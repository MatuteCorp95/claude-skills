# MatuteCorp plugins for Claude

Skills for planning data engineering work with Claude.

| Plugin | What it does |
|---|---|
| [pipeline-automation-planner](plugins/pipeline-automation-planner) | Plan a recurring data process automation end to end, from how it runs today to small contract-based projects with a manager-ready business case. |

## Install in Claude Code

```bash
claude plugin marketplace add MatuteCorp95/claude-skills
claude plugin install pipeline-automation-planner@matutecorp-plugins
```

## Install on claude.ai or the Claude desktop app

Go to **Customize > Plugins > Add > Add marketplace**, paste `https://github.com/MatuteCorp95/claude-skills`, then install **Pipeline Automation Planner**.
